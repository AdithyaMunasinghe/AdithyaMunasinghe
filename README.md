## 🚀 Featured Projects

### 🔍 Digital Forensic Toolkit

A Python-based desktop application that brings essential digital-forensics capabilities together in one interface.

Key capabilities include:

- Connected-device detection and monitoring
- Deleted-file and photo recovery
- Password-cracking workflows
- Disk imaging and acquisition
- Memory analysis
- File-system investigation
- Network traffic analysis
- Steganography detection
- Activity logging, report management and result export
- Automated checking and installation of forensic tools

The toolkit integrates technologies and tools including Python, Tkinter, Linux, PhotoRec, John the Ripper, Guymager, Rekall, Autopsy, Wireshark and StegExpose.

[View the Digital Forensic Toolkit](https://github.com/AdithyaMunasinghe/Bootable-Digital-Forensic-Toolkit-)
